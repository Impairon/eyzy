# Maintained patch references

These are the externally supplied patch references used while improving swizy.

- `0001-Fix-Sibha-peep-real-beep-plus-vibration-with-VIBRATE.patch`
  adds the `VIBRATE` permission and guarded real beep/vibration behavior.
- `0003-Line-mode-one-continuous-bar-over-the-avatar-column.patch`
  documents the continuous avatar-column line approach and related scan optimizations.
- `swizy-feature-bundle.patch` combines both references for convenient review.

The committed Kotlin/XML sources are authoritative; these files are preserved as
reviewable provenance and should not be applied blindly to a newer branch.
