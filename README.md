# swizy

An Android privacy utility with Lowery avatar masking, Sibha counting, and
offline-capable prayer times.

Lowery also includes **Hide an area manually**. Start it from the Lowery tab,
drag across any screen region, and swizy keeps that rectangle black independently
of avatar detection. A small side control can temporarily show or hide the
rectangle, select another area, or remove it.

See [`PROJECT_PATHS.md`](PROJECT_PATHS.md) for the module layout and build/install
commands. The supplied patch references and combined review bundle are kept under
[`patches/`](patches/).
